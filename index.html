HVORFOR NEST FINNES

En oppgaveliste forteller hva som skal gjøres. NEST forteller når det gir mening å gjøre det.

De fleste forsinkelser skyldes ikke mangel på innsats. De oppstår når folk begynner for tidlig, venter uten å vite hvorfor, eller bruker tid på å spørre hvem som gjør hva videre. NEST erstatter den friksjonen med én enkel setning:

«Denne oppgaven blir klar når den forrige er ferdig.»

FØLGESKRIV

For små team som vil bruke mindre tid på å koordinere arbeidet og mer tid på å fullføre det.

NEST Channel er en lett, lokal og kryptert samarbeidsapp bygget rundt betinget oppgavebehandling. Alle installerer samme app og logger inn med GitHub. Telefonene kan være på mobilnett, ulike Wi-Fi eller i forskjellige land. GitHub brukes som tilgjengelig synktransport, mens kanalinnholdet krypteres ende-til-ende før det forlater telefonen. Ingen egen server, root eller Termux er nødvendig.

Oppgaver, ansvarlige, kommentarer, etiketter og kanalchat synkroniseres fortløpende gjennom en skjult GitHub-kanal representert av en Issue og krypterte kommentarer. GitHub ser rom-ID, tidspunkt og kryptert data, men ikke oppgavene eller samtalene.

Dette er ikke prosjektstyring forkledd som et regneark. Det er en enkel arbeidsmåte som lærer teamet å se sammenhengen mellom først, så og nå.
